# Netflix Content Analysis Dashboard

A responsive executive dashboard built with HTML, Tailwind CSS, vanilla JavaScript, Papa Parse, and Chart.js.

## Run locally

```powershell
python -m http.server 8000
```

Open `http://localhost:8000/`.

## Features

- Interactive content, genre, and release-year filters
- Movies and TV Shows portfolio KPIs
- Rating, genre, country, duration, director, and cast charts
- Filter-aware Key Insights
- Searchable title catalog with pagination
- Desktop infographic layout and responsive mobile layout

## Data

Place `netflix_cleaned.csv` in the project root before running the dashboard.
Before publishing the repository, verify and document the original dataset's license and source in `NOTICE.md`.
